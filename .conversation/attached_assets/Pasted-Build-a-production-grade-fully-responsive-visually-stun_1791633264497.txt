Build a production-grade, fully responsive, visually stunning FRONTEND for an API Management & Monitoring Platform called "Serverpulse". It should look and feel like a premium SaaS product (think Vercel, Postman, Datadog and Stripe dashboard quality). NO backend for now: use a mock data layer (fake services + localStorage) so the whole app works on its own and a real backend can be connected later by only changing the files in src/services/.

==================== TECH STACK ====================
Frontend:
- React + TypeScript + Vite (standard structure: index.html, src/main.tsx, src/App.tsx)
- Tailwind CSS + shadcn/ui style components, Lucide icons
- React Router DOM (all routes defined in App.tsx). NO TanStack Router, NO file-based routing
- Axios (used for the API Tester's real requests), Recharts for charts
- Framer Motion for smooth animations
- Simulated real-time updates using setInterval (live logs and status changes), to be replaced by WebSockets later
- Data fetching via custom hooks calling src/services/ (no TanStack Query)
- Mock data: generated seed data persisted in localStorage, with simulated network delay (300-800ms), loading and error states

==================== FRONTEND STRUCTURE ====================
- src/main.tsx: ReactDOM root, BrowserRouter, providers (AuthProvider, ThemeProvider, Toaster)
- src/App.tsx: all <Routes> here: Landing, Login, Register, Dashboard, APIs, API Details, API Tester, Logs, Analytics, Monitoring, API Keys, Alerts, Team, Audit Logs, Docs, Settings, 404. Use a ProtectedRoute and a RoleRoute wrapper
- src/pages/, src/components/ (ui, charts, tables, modals, layout), src/layouts/ (DashboardLayout: sidebar + topbar), src/hooks/, src/services/ (all data access goes only through here, returning Promises shaped like real REST responses), src/mocks/ (seed data generators), src/context/, src/types/, src/utils/
